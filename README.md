# xrt Training

Welcome to the xrt training material.

This workshop is split into two parts:

- [Chapter 1: Environment and calculations](chapter1.md)
- [Chapter 2: GUI and controls](chapter2.md)

Chapter 1 focuses on setting up a reproducible Python environment, installing xrt, and running calculation scripts for sources, materials, mirrors, crystals, and sample spectra.

Chapter 2 will focus on building and operating a beamline more interactively: using the GUI, connecting EPICS process variables, generating CSS BOB screens, and introducing digital twin mode. Bluesky scans are better left for a separate session.
